# Fall 2026 Software Team Projects

Welcome to the Trailblazers Software Team Fall 2026 project hub.

This folder contains the projects completed by the Software Team during the Fall 2026 semester.

Each project includes:

- A project overview
- A guided tutorial
- Required features
- Testing expectations
- Submission instructions
- Optional extensions

Members complete each project in their own personal GitHub repository, then submit their finished work to the Trailblazers repository through a fork and pull request.

---

## Project 1 - System Resource Monitor

Build a Python command-line application that monitors your computer's CPU, memory, and disk usage, displays warnings when resources run high, shows the processes using the most memory, and saves resource snapshots to CSV.

This project focuses on Python fundamentals, Git/GitHub, functions, dictionaries, loops, conditionals, error handling, libraries, file I/O, and project documentation.

**[View Project 1 - System Resource Monitor](./Project%201%20-%20System%20Resource%20Monitor/README.md)**

---

## Project 2 - Ad Blocker

Build a real system-wide Python ad blocker that uses your computer's hosts file to block advertising and tracking domains.

This project builds on the skills from Project 1 and introduces more advanced topics including file processing, sets, operating-system detection, HTTP downloads, DNS concepts, administrator permissions, backups, rollback, and safe system-file modification.

**[View Project 2 - Ad Blocker](./Project%202%20-%20Ad%20Blocker/README.md)**

## Project Workflow

For each project:

1. Read the project README.
2. Follow the tutorial from beginning to end.
3. Build and test the project in your own personal GitHub repository.
4. Make meaningful Git commits as you work.
5. Complete your personal project README.
6. Follow the project's submission instructions.
7. Fork the Trailblazers repository.
8. Add your completed project to your personal submission folder.
9. Open a pull request for review.

---

## Project Repositories

Your personal project repositories should be public so they can be used for:

- Portfolios
- Resumes
- Internship applications
- Interviews
- Future project development

The Trailblazers repository serves as the team's central project archive and submission hub.

---

## AI Policy

AI tools may be used as learning and debugging tools.

However, you must understand and be able to explain any code you submit.

You may be asked to:

- Explain your code
- Walk through a function
- Describe how a feature works
- Debug an issue
- Make a small change to your project

The goal is to build your technical skills, not simply submit working code.

---

## Need Help?

If you run into problems:

- Read the project's troubleshooting section
- Review the error message carefully
- Check your Git/GitHub workflow
- Ask in the Trailblazers Software Team GroupMe
- Bring the issue to a Software Team meeting

When asking for help, include the exact error message and explain what you already tried.
