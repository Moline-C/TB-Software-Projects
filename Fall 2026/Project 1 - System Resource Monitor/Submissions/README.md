## How To Submit

When your project is complete, submit your repository using the **Project 1 Submission Form**:

**[Submit Project 1 Here](PASTE-GOOGLE-FORM-LINK-HERE)**

The form will ask for:

- Your name
- Your GitHub username
- The link to your completed System Resource Monitor repository
- Any optional notes about your project

Your repository link should look similar to:

```text
https://github.com/YOUR-USERNAME/system-resource-monitor
```

Before submitting the form, open the link yourself and make sure:

- The repository opens correctly
- The repository is public
- Your latest code is visible
- Your README displays correctly

Do **not** submit:

- Your GitHub profile link
- The Trailblazers repository
- A local file path from your computer
- A ZIP file
- A screenshot instead of your repository

You only need to submit the link to your completed personal System Resource Monitor repository.
